# So-ho!

Необходимо разработать SPA приложение для Life-style Пространства "Flow".

# Flow — MVP Функциональные и Бизнес-Требования

## 📌 Общая концепция

Flow — это lifestyle-пространство, объединяющее:

- Коворкинг (основной источник дохода)

- Мини-кофейню

- Соседский клуб (мероприятия)

MVP реализуется как:

- Telegram-бот (основной интерфейс)

- SPA веб-приложение (дополнительный доступ)

---

# 🎯 Цель MVP

Запустить систему, позволяющую:

- Продавать доступ в коворкинг

- Управлять посещаемостью

- Обеспечить базовый пользовательский опыт

- Начать генерацию выручки

Срок: 1–2 месяца

# 🔁 User Flows

## 🟢 Flow 1: Покупка тарифа

1. Пользователь открывает Telegram-бот

2. Нажимает “Тарифы”

3. Выбирает тариф

4. Нажимает “Оплатить”

5. Проходит оплату

6. Получает подтверждение

7. Тариф активируется

---

## 🟢 Flow 2: Вход в коворкинг

1. Пользователь открывает “Мой доступ”

2. Показывает экран администратору

3. Администратор проверяет статус

4. Пользователь проходит

---

## 🟢 Flow 3: Выбор места

1. Пользователь открывает “Выбрать место”

2. Видит карту помещения

3. Выбирает номер

4. Подтверждает выбор

---

## 🟡 Flow 4: Заказ кофе

1. Пользователь открывает “Кофе”

2. Выбирает товар

3. Указывает:

   - самовывоз / к месту

4. Оплачивает

5. Получает статус заказа

---

## 🔵 Flow 5: Запись на событие

1. Пользователь открывает “События”

2. Выбирает событие

3. Нажимает “Записаться”

4. Получает подтверждение

---
